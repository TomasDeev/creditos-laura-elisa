# Créditos Laura Elisa

Sitio de conversión para financiamientos e hipotecas en República Dominicana: automotriz, garantía vehicular e hipotecas.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS v4
- Framer Motion
- Resend (formulario de contacto)

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
